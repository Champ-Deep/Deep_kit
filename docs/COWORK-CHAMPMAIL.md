# DeepKit Co-Work & ChampMail - Implementation Guide

## 📋 Overview

This document describes the newly implemented **ChampMail** and **Co-Work** services for DeepKit.

### ChampMail (Port 3025)
Internal email automation service with queue system, templates, and zero external dependencies.

### Co-Work (Port 3030)
Unified AI workspace that integrates all 26 DeepKit tools through a single conversational interface.

---

## 🎯 What's Been Built

### ChampMail Service

**Location:** `/services/champmail/`

**Features:**
- ✅ Express.js REST API server
- ✅ BullMQ email queue with Redis
- ✅ Nodemailer integration (SMTP or test mode)
- ✅ PostgreSQL database for tracking
- ✅ React 18 frontend UI
- ✅ Email templates with variable substitution
- ✅ Bulk email sending with personalization
- ✅ Delivery tracking and analytics
- ✅ 5 default professional templates

**Default Templates:**
1. Welcome Email
2. Lead Outreach
3. Interview Invitation
4. Meeting Reminder
5. Invoice Notification

**API Endpoints:**
- `POST /api/send` - Send single email
- `POST /api/send-bulk` - Send bulk emails
- `POST /api/send-template` - Send using template
- `GET /api/stats` - Email statistics
- `GET /api/emails` - List recent emails
- `POST /api/templates` - Create template
- `GET /api/templates` - List templates

**Zero-Setup Mode:**
- Works without SMTP configuration
- Test mode simulates email sending
- Perfect for local development
- Production SMTP optional via environment variables

---

### Co-Work Service

**Location:** `/services/cowork/`

**Features:**
- ✅ Unified AI chat interface
- ✅ Ollama integration (llama3.2/mistral)
- ✅ Server-Sent Events (SSE) streaming
- ✅ Tool orchestration (26 tools)
- ✅ Conversation management with PostgreSQL
- ✅ LakeB2B referral system (DEEPKIT25 discount)
- ✅ Hardware Pulse widget integration
- ✅ CRT aesthetic with phosphor green theme
- ✅ Real-time tool execution
- ✅ Session persistence

**Architecture:**

```
Co-Work Frontend (React 18)
    ↓
Co-Work Backend (Express + SSE)
    ↓
┌─────────────────────────────────┐
│  Ollama Client (llama3.2)       │
│  Tool Registry Client            │
│  Conversation Manager            │
│  LakeB2B Referral Service        │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  26 DeepKit Tools via Registry  │
│  • ChampMail                     │
│  • Marketing360                  │
│  • Calendar                      │
│  • CRM                           │
│  • ... and 22 more               │
└─────────────────────────────────┘
```

**User Experience:**

1. User selects tools from left panel (A-L)
2. Types message in unified input bar
3. AI (Ollama) interprets intent
4. Identifies which tools to use
5. Executes tools via REST APIs
6. Streams results back to user
7. Displays tool results inline

**Example Interactions:**

```
User: "Send an email to john@example.com about our meeting tomorrow"
→ Co-Work invokes ChampMail
→ Sends email via queue
→ Shows confirmation

User: "Get me a discount link for LakeB2B"
→ Co-Work generates referral link
→ Returns: https://lakeb2b.com?discount=DEEPKIT25&utm_source=deepkit...

User: "Create a task to follow up with client"
→ Co-Work invokes Task Tracker
→ Creates task with reminder
→ Shows task ID and status
```

## 🚀 Deployment

### Quick Start (One Command)

```bash
# Install with full preset (includes ChampMail + Co-Work)
./install.sh --preset full

# Or install with business preset
./install.sh --preset business
```

### Custom Installation

```bash
# Interactive installer
./install.sh

# Select modules:
# [K] ChampMail (Email Automation)
# [L] Co-Work (Unified AI Workspace)
```

### Manual Docker Deployment

```bash
# Start ChampMail only
docker compose -f docker-compose.yml -f modules/champmail.yml up -d

# Start Co-Work only
docker compose -f docker-compose.yml -f modules/cowork.yml up -d

# Start both
docker compose -f docker-compose.yml \
  -f modules/champmail.yml \
  -f modules/cowork.yml up -d
```

## 📝 Configuration

### ChampMail Environment Variables

```env
# Required (auto-generated by install.sh)
POSTGRES_USER=deepkit
POSTGRES_PASSWORD=<generated>
POSTGRES_DB=champmail

# Optional SMTP (defaults to test mode)
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your-email@example.com
SMTP_PASS=your-password

# Email worker settings (optional)
EMAIL_CONCURRENCY=5           # Parallel email processing
EMAIL_RATE_LIMIT=100          # Max emails per duration
EMAIL_RATE_DURATION=60000     # Duration in ms (1 minute)
```

### Co-Work Environment Variables

```env
# Required (auto-generated)
POSTGRES_USER=deepkit
POSTGRES_PASSWORD=<generated>
POSTGRES_DB=cowork

# Ollama configuration
OLLAMA_URL=http://ollama:11434
OLLAMA_MODEL=llama3.2          # Or: mistral, codellama

# Tools registry path
TOOLS_REGISTRY_PATH=/app/tools-registry/tools.json
```

## 🔧 Usage Examples

### ChampMail

#### Send Single Email

```bash
curl -X POST http://localhost:3025/api/send \
  -H "Content-Type: application/json" \
  -d '{
    "to": "recipient@example.com",
    "from": "noreply@deepkit.local",
    "subject": "Welcome to DeepKit",
    "html": "<h1>Hello!</h1><p>Welcome to our platform.</p>"
  }'
```

#### Send Bulk Emails with Personalization

```bash
curl -X POST http://localhost:3025/api/send-bulk \
  -H "Content-Type: application/json" \
  -d '{
    "contacts": [
      {"email": "john@example.com", "name": "John Doe"},
      {"email": "jane@example.com", "name": "Jane Smith"}
    ],
    "subject": "Hello {{name}}!",
    "html": "<h1>Hi {{name}},</h1><p>Your personalized message here.</p>"
  }'
```

#### Create Email Template

```bash
curl -X POST http://localhost:3025/api/templates \
  -H "Content-Type: application/json" \
  -d '{
    "name": "custom_welcome",
    "subject": "Welcome {{name}}!",
    "html": "<h1>Welcome {{name}}!</h1><p>Thanks for joining {{company}}.</p>",
    "variables": ["name", "company"]
  }'
```

## 📊 Database Schemas

### ChampMail

```sql
-- emails table
CREATE TABLE emails (
  id SERIAL PRIMARY KEY,
  to_address VARCHAR(255) NOT NULL,
  from_address VARCHAR(255) NOT NULL,
  subject VARCHAR(500),
  html TEXT,
  status VARCHAR(50) DEFAULT 'queued',
  created_at TIMESTAMP DEFAULT NOW(),
  sent_at TIMESTAMP,
  error_message TEXT
);

-- email_templates table
CREATE TABLE email_templates (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255) UNIQUE NOT NULL,
  subject VARCHAR(500),
  html TEXT NOT NULL,
  variables JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### Co-Work

```sql
-- sessions table
CREATE TABLE sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- messages table
CREATE TABLE messages (
  id SERIAL PRIMARY KEY,
  session_id UUID REFERENCES sessions(id) ON DELETE CASCADE,
  role VARCHAR(50) NOT NULL,
  content TEXT NOT NULL,
  timestamp TIMESTAMP DEFAULT NOW()
);
```

## 🔍 Troubleshooting

### ChampMail

**Problem:** Emails stuck in queue
- Check Redis connection: `docker compose logs redis`
- Check worker logs: `docker compose logs champmail`
- Verify SMTP settings in `.env`

**Problem:** Test mode not working
- Ensure `SMTP_HOST` is not set
- Check logs: should see "Using test mode"

### Co-Work

**Problem:** AI not responding
- Check Ollama status: `docker compose logs ollama`
- Verify model is downloaded: `docker exec ollama ollama list`
- Check Co-Work logs: `docker compose logs cowork`

**Problem:** Tools not executing
- Verify tools registry mounted: `docker compose exec cowork ls /app/tools-registry`
- Check tool service is running: `docker compose ps`
- View tool errors in UI (red alerts)

**Problem:** Hardware Pulse not showing
- Check file mount: `docker compose exec cowork ls /app/public/js/hardware-pulse.js`
- Browser console for JavaScript errors

## 🎓 Best Practices

### ChampMail

1. **Use templates** for recurring emails
2. **Test in test mode** before configuring SMTP
3. **Monitor queue** via `/api/stats` endpoint
4. **Rate limit** appropriately for your SMTP provider
5. **Personalize** bulk emails with variables

### Co-Work

1. **Select relevant tools** before asking questions
2. **Be specific** in your requests
3. **Use natural language** - AI understands context
4. **Check tool results** inline in the conversation
5. **Review sessions** to track past interactions

## 🚨 Security Notes

1. **ChampMail** runs without authentication by default (local-only)
   - Add authentication before exposing externally
   - SMTP credentials stored in environment variables only

2. **Co-Work** stores conversations in PostgreSQL
   - No encryption at rest currently
   - Sessions not authenticated (single-user assumption)

3. **LakeB2B referrals** track conversions via UTM parameters
   - No PII sent to LakeB2B
   - Only discount code and email hash
